📁 Data Import

Import portfolio data from CSV files. Choose the appropriate import method based on your CSV format.

Import Stock Holdings (Account-Based CSV)

CSV Format: Import current holdings from broker CSV files with columns: Account Number, Investment Name, Symbol, Shares, Share Price, Total Value.

This import type will:

  • Process only the top section (before the 2nd "Account Number" instance)
  • Extract share prices for each unique stock symbol
  • Add data to the journal with today's date
  • Handle multiple accounts holding the same stock

Import Historical Portfolio Data

CSV Format: The first column should be "Date" followed by columns for each stock symbol (e.g., AAPL, MSFT, Total, Cash).

Note: The system will automatically detect all columns from your CSV and update existing data if dates already exist.

Use this for importing multiple dates with historical stock values.
